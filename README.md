# Cadence-Peak-Detection-IMU
Using acceleration and angular velocity data from one 9 sense IMU at my ankle. I gathered and detected cadence through a peak detection method referenced from the paper titled, "Walking and running cadence estimation using a single trunk-fixed accelerometer for daily physical activities assessment". The initial data was collected using the PlatformIO extension. The acceleration norm was found first, the sampling rate was then brought down to 40hz, filtered through a low pass FIR filter, Transformed via a CWT, filtered one last time using a Savitzky–Golay filter, the peaks were extrapolated from the final result, cadence was calculated based off of each peak.
